## Наблюдения

- **Reflection сработала там, где нужно:** на задачах 2 и 3 critic зафиксировал
  ошибку подключения и выдал REVISE, после чего react дал честный ответ о
  недоступности базы вместо того чтобы замолчать проблему.

- **На провокационной задаче (арифметика) оба агента не вызвали tools** —
  ни naive, ни react не попытались использовать инструменты для простого
  вычисления. Системный промпт ReAct сработал корректно.

- **React тратит больше токенов:** каждый шаг добавляет critic-вызов (~250–400
  токенов), поэтому итоговый счёт react в 1.5–2 раза выше naive. Это цена
  за самопроверку.

- **Naive уходил в цикл молча:** на задачах 2 и 3 naive просто вернул общий
  отказ без объяснения причины. React явно указал на ошибку подключения —
  более информативный ответ пользователю.

- **Счётчик ревизий не сбросился между итерациями:** на задачах 2 и 3 было
  по одной ревизии, лимит 2 не превышен ни разу.
